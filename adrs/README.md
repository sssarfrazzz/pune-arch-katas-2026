# Architecture Decision Records

ADRs capture decisions that materially constrain the Von Digitalis Estates architecture. Each record states the context, decision, alternatives, consequences, and follow-up questions. Requirements and diagrams remain the source for what the system must do; ADRs explain how the architecture will approach it.
