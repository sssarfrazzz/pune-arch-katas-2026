# Glossary

| Field | Value |
|---|---|
| Document ID | GOV-002 |
| Status | Draft |
| Date | 2026-09-15 |
| Source | [Solution Overview](../../solution-overview-15thSept.md) |

| Term | Definition |
|---|---|
| Autonomous Actuation Layer | Product 2, which executes approved physical missions through certified robot and drone classes. |
| Bronze data | Raw local evidence retained according to policy before quality promotion. |
| Consequential action | An action affecting safety, welfare, finance, legal position, public communication, or physical operation and requiring authorized human approval. |
| Cost Pool | A governed financial allocation source that does not earn Unit Credits. |
| Domain subject | An animal or managed population represented by records but holding no credentials or permissions. |
| Estate Edge | Site-local compute, storage, radio, workflow, and dashboard capabilities. |
| Gold data | Purpose-ready governed data promoted for reporting or analytical use. |
| Human-in-the-loop | A control model in which authorized people approve consequential actions and retain accountability. |
| Independent safety system | Certified ride, containment, fire, or life-support control outside platform control. |
| Operational Unit | An immutable ride or enclosure identity linking operational, workforce, visitor, maintenance, cost, and revenue evidence. |
| Operations Intelligence Platform | Product 1, covering sensing, detection, recommendations, operational coordination, and evidence. |
| Pass Token | A planned prepaid visitor entitlement; it is not a cryptocurrency and is separate from Unit Credits and Visitor Coins. |
| Safer state | A state that withholds availability or action when required evidence, authority, or connectivity is absent. |
| Silver data | Validated and normalized local evidence promoted from Bronze data. |
| Unit Credit | An internal, non-transferable management-accounting measure calculated from validated visitor-minutes and a unit weight. |
| Visitor Coin | A closed-loop promotional loyalty reward separate from Unit Credits and Pass Tokens. |

Terms not defined here retain the meaning used in the canonical source. Disputed terms are recorded in [Assumptions and Open Items](assumptions-and-open-items.md).
